# Designs

Create and manage display designs, each built from a worksheet and a set of project requirements.

## Prerequisites

- The **Designs** area must be enabled for your tenant. If you do not see it in the top navigation, it is not enabled for your account.
- To link a design to an opportunity, that opportunity must exist in the connected NetSuite account.

## Create a design

1. Open **Designs** from the top navigation.
2. Select **New Design**.
3. In **Search Opportunities**, type a customer name or opportunity number and pick a result to link it. To create an unlinked design instead, select **Skip (Blank Design)**.
4. Enter a **Design Name**. Linked designs are pre-filled with the customer and opportunity number; adjust as needed.
5. Select **Create Design**.

## Result

The design is created with a starter worksheet and the default requirement categories, and it opens ready to edit. Linked designs show an **Opp** badge with the opportunity number.

## Find and open a design

The Designs list shows every design for your tenant, newest first, with its opportunity, customer, status, sales rep, and created date.

- Use the search box to match on name, opportunity, customer, or sales rep.
- Narrow the list with the **All Sales Reps** and **All Customers** filters.
- Select any row to open the design.

## Edit a design

Inside a design you can:

- **Rename it** — select the design name in the header, type a new name, and press Enter.
- **Switch tabs** — use **Worksheet** to build the equipment and labor estimate, or **Requirements** to capture and track project requirements. See [Requirements](requirements.md).
- **Manage worksheets** — when more than one exists, use the worksheet selector in the header to switch between them, the pencil to rename the active one, or **+ New** to add another.

## Delete a design

1. In the Designs list, select the trash icon on the design's row.
2. Select **Delete** to confirm, or **Cancel** to keep it.

!!! warning "Deletion is permanent"
    Deleting a design also removes its worksheets and requirements. This cannot be undone.

## Tips

- The item, category, and labor data available in a worksheet comes from the shared [Catalog](catalog.md). Set the catalog up first so new designs have everything they need.
